# Analysis feedback

Track when a video fails to produce a useful place suggestion, so the team can find patterns and improve extraction and analysis.

- Record explicit "wrong place" feedback and user corrections against the video and suggestion.
- Keep enough analysis context to investigate which videos and processing versions fail.
- [[incorrect-analysis-safeguards]] covers editing the suggested place and possible ways to learn from those edits.
