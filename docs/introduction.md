## What is this folder?

This is a knowledge base for the TravelTok codebase. Hard to tell what this will contain, but for now the main focus is documenting the different ways in which we can get relevant data about the shorts (videos, comments etc.) from platforms (TikTok, Instagram, Yt, etc.).

## What is TravelTok?

TravelTok is a project which would allow the user of a short-form video platform to gather shorts about certain places (despite the travel in the name, I now realize that it will work just as well for exploring places in your city aswell, so that is something to keep in mind aswell), where the video then gets analyzed, pinpointed on map. Initially the app will be barebones - just a list of locations and a map, with things maybe nicely grouped. Later some other features are condiered to be added, mostly described in [[features/index]].

This whole folder should probably be also converted to notion once this project gets serious.
